## Independent model matrix

`test/models/current_protocol_model.py` imports no Solidity artifacts or SDK helpers. Two deterministic seeds execute 2,000 randomized lifecycle/ownership/economic sequences each and terminally drain obligations. Separate deterministic tests cover integer splits, modulo exactness, selective-reveal advantage, and both race orderings. This is an independent abstract model, not a byte-for-byte EVM differential and not a formal proof.

## Known matrix gaps

- No fresh Halmos path counts because the tool/setup is unavailable.
- The custom current-source sample finished 38/38 after eight test-gap survivors were killed; Gambit operator enumeration remains unavailable and event mutations are not included.
- External fuzz harnesses do not expose durable per-lifecycle-branch counters, although separate cash/NFT runs retained nontrivial corpora.
- Cross-factory nesting is tested at depth two, not exhaustively for arbitrary depth/cycles.
- Deployment validation does not yet prove an expected Factory runtime identity, and the subgraph does not index `EntropyCallbackIgnored`.

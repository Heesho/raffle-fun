usage: run_native_gemini.py [-h] --workspace WORKSPACE
                            --prompt-file PROMPT_FILE --output-dir OUTPUT_DIR
                            [--agent AGENT] [--mode {plan,auto,accept-edits}]

Run an explicitly prepared prompt in a fresh native Antigravity session. No
wall-clock timeout, automatic retries, continuation, fallback, or report
import. The controller must prepare and verify the workspace and pinned
resources first.

options:
  -h, --help            show this help message and exit
  --workspace WORKSPACE
  --prompt-file PROMPT_FILE
  --output-dir OUTPUT_DIR
  --agent AGENT         Prepared workspace custom agent name
  --mode {plan,auto,accept-edits}

**Purpose:** This override is the common pre-hook for ticket ownership changes. It rejects a nonzero recipient classified as same-factory protocol plumbing, then delegates authorization, approval clearing, balance changes, owner storage, and the ERC-721 `Transfer` event to the inherited ledger (`target/packages/contracts/src/Raffle.sol:L491-L502`; `target/packages/contracts/node_modules/@openzeppelin/contracts/token/ERC721/ERC721.sol:L216-L244`). Burns pass `address(0)`, skip destination classification, and still delegate the ownership deletion to the inherited implementation (`target/packages/contracts/src/Raffle.sol:L492-L501`). The hook does not read raffle lifecycle status, so the inherited public transfer surface applies the same destination rule in every lifecycle state (`target/packages/contracts/src/Raffle.sol:L491-L502`; `target/packages/contracts/node_modules/@openzeppelin/contracts/token/ERC721/ERC721.sol:L114-L136`).

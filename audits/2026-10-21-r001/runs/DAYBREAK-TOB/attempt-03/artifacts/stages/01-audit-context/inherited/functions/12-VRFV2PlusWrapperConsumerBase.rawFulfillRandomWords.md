## `rawFulfillRandomWords` in `target/packages/contracts/node_modules/@chainlink/contracts/src/v0.8/vrf/dev/VRFV2PlusWrapperConsumerBase.sol` (L101-L107)

**Purpose:** This inherited external gateway is the authentication boundary between the configured VRF wrapper and `Raffle`'s internal randomness handler. It rejects every caller other than the immutable `i_vrfV2PlusWrapper`, then dynamically dispatches the supplied request ID and words to `Raffle.fulfillRandomWords` (`target/packages/contracts/node_modules/@chainlink/contracts/src/v0.8/vrf/dev/VRFV2PlusWrapperConsumerBase.sol:L34-L46`, `L99-L107`; `target/packages/contracts/src/Raffle.sol:L28`, `L509-L524`). In the Raffle use, that dispatch either records an ignored authenticated callback or changes a raffle from `Drawing` to `NftWon`/`CashWon`; the gateway itself does not decide request correlation, word count, callback timing, or raffle lifecycle (`target/packages/contracts/src/Raffle.sol:L509-L523`).

**Inputs & Assumptions:**

Trust is **untrusted at entry** because any address can call this external function, and **wrapper-controlled after L103-L105** because only the configured wrapper reaches the dispatch. Raffle independently compares it with stored `vrfRequestId` (`target/packages/contracts/node_modules/@chainlink/contracts/src/v0.8/vrf/dev/VRFV2PlusWrapperConsumerBase.sol:L101-L106`; `target/packages/contracts/src/Raffle.sol:L108-L109`, `L509-L515`).
- `_randomWords` (`uint256[] memory`): externally ABI-decoded words. Trust is **untrusted at entry** and **wrapper-controlled after authentication**. The gateway places no bound on the array; Raffle accepts exactly one element and ignores every other ABI-decodable length (`target/packages/contracts/node_modules/@chainlink/contracts/src/v0.8/vrf/dev/VRFV2PlusWrapperConsumerBase.sol:L101-L106`; `target/packages/contracts/src/Raffle.sol:L504-L515`).

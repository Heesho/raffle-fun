# Native workflow host declaration
This run executes an explicitly declared six-stage aggregate, not the full Trail of Bits catalog.
The configured tool surface provides collaboration agents and local execution but no upstream Workflow command. The pinned audit-context.js and spec-compliance.js files are executed as JavaScript using audit/workflow-host.cjs. Their control flow, prompts, fan-out, schemas, ranking, barriers, refutation rules, and report construction remain intact. The host changes only `export const meta =` to `const meta =` because upstream scripts use top-level return and expect a workflow host. Both original and hosted bytes are retained per stage.
Host primitives: phase/log append a timestamped JSONL journal; agent publishes a schema-bearing request, waits for an atomic response, and validates it recursively; pipeline preserves input order and composes each per-item stage; parallel awaits every supplied task; budget is unset, explicit limits govern fan-out. The root bridges each published request to one independent collaboration agent. No alternate model is called. A schema violation aborts the host, disabling upstream's potential default-agent retry path.
The actual collaboration dispatch specifies gpt-6-astra with reasoning_effort=ultra for every agent, including discovery, orientation, verification and reporting. Native requested low/medium effort is recorded but overridden by the user's exact-selection instruction. Provider response metadata does not include a model field; provider model and effort are unknown. The user's runner statement is evidence of local root selection only, not provider identity.
S1 uses the pinned workflow with limit 12 (native default), with coverage explicitly naming candidates below the cut. S5 uses limit up to the native maximum 30 as time permits. Tool-assisted stages and any runtime incompatibilities will be listed separately; this adapter does not imply availability of Slither/Echidna/Manticore.
Source-only stages run in requested order. Each source-only stage is sealed before S6 tool execution. No external reconciliation is performed. S1 per-function agents consume orientation only; S1 synthesis consumes their records by native design. S2-S4 receive target source and their own skill/resources only. S5 discovery/extraction/checkers receive source/spec only; its independent refuters and report agent receive native alignment outputs by design. They do not receive S3/S4 findings.

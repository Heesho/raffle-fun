## REQ-16-4 — ERC-721 prize deposit requires previous owner (`from`) to be the configured sponsor

> "Previous owner, which must be the configured sponsor."
> — `packages/contracts/src/Raffle.sol:L413` (`Raffle.onERC721Received` NatSpec, `packages/contracts/src/Raffle.sol:L413-L425`)

**Verdict:** implemented · confidence: high

---

**What this demands of an implementation:**

When `Raffle.onERC721Received(address operator, address from, uint256 tokenId, bytes calldata)` is called, the `from` parameter (representing the previous ERC-721 owner) must equal the raffle's configured `sponsor` storage variable (`Raffle.sol:L61`, initialized once in `Raffle.initialize` at `Raffle.sol:L197`). If `from != sponsor`, `onERC721Received` must revert with `UnexpectedPrize(msg.sender, tokenId, from, operator)` (`IRaffle.sol:L202`).

---

**Where enforcement lives:**

```solidity
// packages/contracts/src/Raffle.sol:L416-L431
function onERC721Received(address operator, address from, uint256 tokenId, bytes calldata)
    external
    override
    returns (bytes4 selector)
{
    if (
        status != Status.AwaitingPrize || msg.sender != address(prizeToken) || tokenId != prizeTokenId
            || from != sponsor || operator != factory
    ) {
        revert UnexpectedPrize(msg.sender, tokenId, from, operator);
    }

    status = Status.Active;
    emit PrizeDeposited(msg.sender, tokenId, from);
    selector = IERC721Receiver.onERC721Received.selector;
}
```

## REQ-25 — Transaction decisions reread current chain state

> "Frontend discovery is advisory; transaction decisions must reread current chain state."
> — DESIGN.md # Clean design specification, L2

**Verdict:** implemented · confidence: high

---

**What this demands of an implementation:**

1. Every on-chain state-changing entry point in `RaffleFactory` and `Raffle` must read and validate live chain state during execution—including lifecycle `status`, `block.timestamp`, `totalEntries`, `ticketCount`, `_ticketRanges[ticketId]`, `winningEntry`, current ERC-721 ticket ownership via `ownerOf(ticketId)`, live Chainlink VRF wrapper request pricing via `calculateRequestPriceNative`, live factory clone registry state via `isRaffle`, and post-transfer ERC-721 prize ownership via `prizeToken.ownerOf(prizeTokenId)`—rather than trusting off-chain discovery inputs or stale snapshots.
2. On-chain view getters must expose authoritative contract state so callers and off-chain clients can reread current chain state before submitting transactions.
3. Insofar as the requirement also prescribes off-chain client/frontend behavior prior to submitting a transaction, `packages/contracts` contains only Solidity smart contracts and cannot enforce off-chain client pre-submission reads beyond reverting transactions whose preconditions fail against live on-chain state.

function requestDraw() external payable override nonReentrant returns (uint256 requestId) {

function redeemWinningTicket(uint256 ticketId) external override nonReentrant returns (uint256 cashAmount) {
    if (winnerRedeemed) revert WinningTicketAlreadyRedeemed();
    Status result = status;
    if (result != Status.NftWon && result != Status.CashWon) revert InvalidStatus(result);

    if (!settlementComplete) {
        _settleWinningTicket(ticketId);
    } else if (ticketId != winningTicketId) {
        revert WinningTicketMismatch(ticketId, winningTicketId);
    }

    address winner = ownerOf(ticketId);
    if (msg.sender != winner) revert NotTicketOwner(ticketId, msg.sender, winner);

    winnerRecipient = winner;
    winnerRedeemed = true;
    _burn(ticketId);

    address deliveredPrizeToken = address(0);
    uint256 deliveredPrizeTokenId = 0;
    if (result == Status.NftWon) {
        if (prizeClaimed) revert PrizeAlreadyClaimed();
        prizeClaimed = true;
        deliveredPrizeToken = address(prizeToken);
        deliveredPrizeTokenId = prizeTokenId;
        prizeToken.transferFrom(address(this), winner, deliveredPrizeTokenId);
        if (prizeToken.ownerOf(deliveredPrizeTokenId) != winner) {
            revert PrizeDeliveryVerificationFailed(winner);
        }
    } else {
        cashAmount = winnerProceeds;
        if (cashAmount == 0) revert NoWinnerProceeds();
        winnerProceeds = 0;
        _transferQuote(winner, cashAmount);
    }

function refundTickets(uint256[] calldata ticketIds) external override nonReentrant returns (uint256 amount) {
    _requireStatus(Status.Refunding);
    uint256 ticketQuantity = ticketIds.length;
    if (ticketQuantity == 0 || ticketQuantity > RaffleConstants.MAX_REFUND_TICKET_BATCH_SIZE) {
        revert InvalidTicketBatchSize(ticketQuantity, RaffleConstants.MAX_REFUND_TICKET_BATCH_SIZE);
    }

    uint256 aggregateEntries = 0;
    for (uint256 index; index < ticketQuantity; ++index) {
        uint256 ticketId = ticketIds[index];
        address owner = ownerOf(ticketId);
        if (msg.sender != owner) revert NotTicketOwner(ticketId, msg.sender, owner);

        (uint128 firstEntry, uint128 lastEntry) = ticketRange(ticketId);
        aggregateEntries += uint256(lastEntry) - uint256(firstEntry) + 1;
        _burn(ticketId);
    }

    amount = aggregateEntries * ENTRY_PRICE;
    remainingRefundLiability -= amount;
    _transferQuote(msg.sender, amount);
    uint256 liabilityAfter = remainingRefundLiability;

- **Lifecycle and timestamp checks:** `_requireStatus` (`Raffle.sol:L573-L575`) reads live `status` on `buyEntries` (`L215`), `requestDraw` (`L241`), and `refundTickets` (`L350`); `enableRefunds` (`L279-L294`), `redeemWinningTicket` (`L311-L312`), `_settleWinningTicket` (`L535-L536`), `releaseSponsorPrize` (`L396-L399`), `onERC721Received` (`L422`), and `fulfillRandomWords` (`L511`) read live `status` directly. `createRaffle` (`RaffleFactory.sol:L99-L104`), `buyEntries` (`Raffle.sol:L216`), `requestDraw` (`L242, L244-L247`), `enableRefunds` (`L282, L287, L291`), and `fulfillRandomWords` (`L512, L520`) read live `block.timestamp`.
- **Advisory candidate winning ticket verification:** Because `fulfillRandomWords` records only `winningEntry` in `[1, totalEntries]` (`Raffle.sol:L518-L519`), callers discover the winning `ticketId` off-chain and pass it to `settleWinningTicket(ticketId)` or `redeemWinningTicket(ticketId)`. `_settleWinningTicket` calls `_requireWinningTicket(ticketId)` (`Raffle.sol:L538, L579-L585`), which rereads `_ticketRanges[ticketId]` (`L451-L455`) and `winningEntry` (`L581`) from storage and reverts with `TicketDoesNotContainWinningEntry` if `selectedEntry < firstEntry || selectedEntry > lastEntry`.
- **Live bearer ticket ownership at redemption and refund:** `_settleWinningTicket` does not cache a winner address (`Raffle.sol:L528-L529, L533-L558`). `redeemWinningTicket` reads `ownerOf(ticketId)` (`Raffle.sol:L320` -> `ERC721.sol:L61-L63, L425-L432, L146-L148`) at redemption execution time, verifies `msg.sender == winner` (`Raffle.sol:L321`), and burns the ticket (`L325`). `refundTickets` reads `ownerOf(ticketId)` (`Raffle.sol:L359`) and burns each ticket (`L364`) inside the loop so subsequent iterations reread updated `_owners[ticketId]` state and revert on duplicates.
- **Live VRF fee rereads:** `requestDraw` queries `getVrfRequestPrice()` (`Raffle.sol:L249, L436-L438` -> `i_vrfV2PlusWrapper.calculateRequestPriceNative(callbackGasLimit, 1)`) and `requestRandomnessPayInNative` (`L257` -> `VRFV2PlusWrapperConsumerBase.sol:L82-L86`), which recalculates `calculateRequestPriceNative` at execution time, verifies `paidPrice <= msg.value` (`Raffle.sol:L258`), and refunds `msg.value - paidPrice` (`L262-L270`). `IRaffle.sol:L360` explicitly notes that the quoted fee "may change before request inclusion."
- **Post-external-call state rereads and live destination screening:** `createRaffle` rereads `prize.ownerOf(params.prizeTokenId) == raffle` and `IRaffle(raffle).status() == IRaffle.Status.Active` (`RaffleFactory.sol:L129-L134`) after `safeTransferFrom`. `redeemWinningTicket` (`Raffle.sol:L335-L337`) and `releaseSponsorPrize` (`L405`) reread `prizeToken.ownerOf(...)` after `transferFrom`. `_update` (`L498`) and `_transferQuote` (`L565`) call `_isProtocolDestination` (`L593-L605`), which reads live `destination.code.length` (`L602`) and `canonicalFactory.isRaffle(destination)` (`L603`) at transfer/payout time.

**How the verdict was reached:**

Every state-changing path in `RaffleFactory.sol` and `Raffle.sol` reads and validates live on-chain state during execution rather than trusting off-chain discovery or cached values: lifecycle transitions recheck `status` and `block.timestamp`; entry purchases compute ranges from live `totalEntries` and `ticketCount`; draw initiation queries the live VRF fee from the Chainlink wrapper via `getVrfRequestPrice()` and `requestRandomnessPayInNative`; settlement verifies a candidate `ticketId` against live `_ticketRanges[ticketId]` and `winningEntry`; redemption and refunds check live `ownerOf(ticketId)` immediately prior to burning; quote-token payouts and ticket transfers recheck live `_isProtocolDestination` (including `canonicalFactory.isRaffle`); and NFT escrow/delivery paths reread `prizeToken.ownerOf(prizeTokenId)` and `IRaffle(raffle).status()` after external `safeTransferFrom`/`transferFrom` calls. Furthermore, `Raffle` and `RaffleFactory` expose complete view functions for callers to reread current chain state before submitting transactions. Therefore, the verdict is `implemented` rather than `partial`.

> "Deployment tooling must

> "The quote token must report exactly six decimals; the wrapper and quote token must contain deployed code.

> ///      cannot prove token identity from metadata."

> "Quote token and Chainlink wrapper are trusted canonical dependencies; arbitrary prize contracts and ticket recipients are untrusted."

**Verdict:** absent · confidence: high

---

**What this demands of an implementation:**

Offchain or script-based deployment tooling must verify before or during `RaffleFactory` deployment that the `quoteToken_` address passed to `RaffleFactory.constructor(address quoteToken_, address vrfWrapper_, address protocolTreasury_)` (and stored in the immutable `quoteToken` variable on both `RaffleFactory` and the `Raffle` implementation) matches the target chain's official canonical USDC contract address.

---

**Where enforcement lives:**

No enforcement of official target-chain USDC address identity exists in the scoped codebase (`packages/contracts`). No deployment scripts, configuration files, or verification tooling are present in scope.

Onchain construction in `RaffleFactory.sol` and `Raffle.sol` enforces only contract code presence, non-zero address, and six-decimal `IERC20Metadata` reporting, while explicitly delegating canonical USDC identity verification to external deployment tooling:

```solidity
// packages/contracts/src/RaffleFactory.sol:L65-L92
    constructor(address quoteToken_, address vrfWrapper_, address protocolTreasury_) {
        _requireContract(quoteToken_);
        _requireContract(vrfWrapper_);
        if (protocolTreasury_ == address(0)) revert ZeroAddress();

        uint8 quoteDecimals = 0;
        try IERC20Metadata(quoteToken_).decimals() returns (uint8 decimals_) {
            quoteDecimals = decimals_;
        } catch {
            revert UnsupportedQuoteToken(quoteToken_);
        }
        if (quoteDecimals != RaffleConstants.QUOTE_TOKEN_DECIMALS) {
            revert InvalidQuoteTokenDecimals(quoteDecimals, RaffleConstants.QUOTE_TOKEN_DECIMALS);
        }

        if (protocolTreasury_ == address(this) || protocolTreasury_ == quoteToken_ || protocolTreasury_ == vrfWrapper_)
        {
            revert UnsafeProtocolDestination(protocolTreasury_);
        }

        quoteToken = quoteToken_;
        vrfWrapper = vrfWrapper_;
        protocolTreasury = protocolTreasury_;

        address implementation = address(new Raffle(quoteToken_, vrfWrapper_));
        if (protocolTreasury_ == implementation) revert UnsafeProtocolDestination(protocolTreasury_);
        raffleImplementation = implementation;
    }
```

- `RaffleFactory.sol:L70-L78` queries `IERC20Metadata(quoteToken_).decimals()` and requires the returned value to equal `RaffleConstants.QUOTE_TOKEN_DECIMALS` (`6`, defined at `RaffleConstants.sol:L24`).
- `RaffleFactory.sol:L89` deploys `new Raffle(quoteToken_, vrfWrapper_)`, whose constructor at `Raffle.sol:L155-L166` checks `if (msg.sender == address(0) || quoteToken_ == address(0)) revert ZeroAddress();` (`Raffle.sol:L159`) and assigns `quoteToken = IERC20(quoteToken_);` (`Raffle.sol:L162`).
- Any deployed contract returning `uint8(6)` from `decimals()` passes all onchain constructor checks.

## REQ-17-4 — `onERC721Received` requires transferred `tokenId` to match configured `prizeTokenId`

> "Transferred token ID, which must match the configured prize."
> — `packages/contracts/src/Raffle.sol:L414` (in `onERC721Received` NatSpec and implementation at `packages/contracts/src/Raffle.sol:L414-L425`)

---

**Verdict:** implemented · confidence: high

**What this demands of an implementation:**

When `Raffle.onERC721Received(address operator, address from, uint256 tokenId, bytes calldata)` is invoked, the callback must verify that the supplied `tokenId` parameter equals the raffle's configured `prizeTokenId` state variable, and if `tokenId != prizeTokenId`, it must revert with `IRaffle.UnexpectedPrize(msg.sender, tokenId, from, operator)`.

```solidity
// packages/contracts/src/Raffle.sol:L416-L431
    function onERC721Received(address operator, address from, uint256 tokenId, bytes calldata)
        external
        override
        returns (bytes4 selector)
    {
        if (
            status != Status.AwaitingPrize || msg.sender != address(prizeToken) || tokenId != prizeTokenId
                || from != sponsor || operator != factory
        ) {
            revert UnexpectedPrize(msg.sender, tokenId, from, operator);
        }

        status = Status.Active;
        emit PrizeDeposited(msg.sender, tokenId, from);
        selector = IERC721Receiver.onERC721Received.selector;
    }
```

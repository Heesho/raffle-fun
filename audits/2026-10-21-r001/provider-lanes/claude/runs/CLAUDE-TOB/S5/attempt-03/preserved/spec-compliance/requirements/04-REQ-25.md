## REQ-25 — No upgrade path for the factory or any raffle

> "No administrator, mutable configuration or upgrade."
> — DESIGN.md line 2, sentence 9

Supporting text from the same line: "Ethereum NFT raffle; immutable factory, ERC-1167 clones with immutable implementation."
(DESIGN.md line 2, sentence 1)

This record covers the **upgrade** clause only. The task gives the holds-if criterion (these are the task's words, not
DESIGN.md's): "Neither the factory nor any raffle can be upgraded: no UUPS, transparent or beacon proxy, no mutable
delegatecall target, no selfdestruct." The administrator and mutable-configuration clauses of the same sentence are not
judged here.

**Verdict:** implemented · confidence: high

---

**What this demands of an implementation:** this is a prohibition, so the property holds only if no reachable path
offers any mechanism that changes the code a call to the factory or a raffle executes. Concretely:

1. `RaffleFactory` is not a proxy and inherits no upgrade logic: no ERC-1967 slot, no `upgradeTo`/`upgradeToAndCall`/
   `_authorizeUpgrade`, no beacon lookup.
2. Each raffle clone's delegatecall target is fixed when the clone is created, and nothing written later can change it.
3. The implementation that every clone delegates to cannot be destroyed or replaced. No SELFDESTRUCT is reachable from
   `Raffle`, its bases, or the clone runtime.
4. No other `delegatecall` whose target comes from storage or calldata is reachable from `Raffle` or `RaffleFactory`.

---

**Where enforcement lives:**

The clone target is an immutable, written once:

```solidity
// RaffleFactory.sol:L42
address public immutable override raffleImplementation;
// RaffleFactory.sol:L89-L91 (constructor)
address implementation = address(new Raffle(quoteToken_, vrfWrapper_));
if (protocolTreasury_ == implementation) revert UnsafeProtocolDestination(protocolTreasury_);
raffleImplementation = implementation;
// RaffleFactory.sol:L106 (createRaffle)
raffle = Clones.clone(raffleImplementation);
```

The clone embeds that address as a literal:

```solidity
// node_modules/@openzeppelin/contracts/proxy/Clones.sol:L51-L58
assembly ("memory-safe") {
    mstore(0x00, or(shr(232, shl(96, implementation)), 0x3d602d80600a3d3981f3363d3d373d3d3d363d73000000))
    mstore(0x20, or(shl(120, implementation), 0x5af43d82803e903d91602b57fd5bf3))
    instance := create(value, 0x09, 0x37)
}
```

- Decoded, the 0x37-byte initcode is `3d602d80600a3d3981f3`: CODECOPY 0x2d bytes from offset 0x0a, then RETURN. The
  45-byte runtime that follows is `363d3d373d3d3d363d73 <20-byte implementation> 5af43d82803e903d91602b57fd5bf3`. As
  opcodes: CALLDATASIZE, RETURNDATASIZE ×2, CALLDATACOPY, RETURNDATASIZE ×3, CALLDATASIZE, RETURNDATASIZE,
  **PUSH20 <implementation>**, GAS, **DELEGATECALL**, RETURNDATASIZE, DUP3, DUP1, RETURNDATACOPY, SWAP1,
  RETURNDATASIZE, SWAP2, PUSH1 0x2b, JUMPI, REVERT, JUMPDEST (at 0x2b), RETURN. The target is a PUSH20 operand in the
  code. The runtime contains no SLOAD, SSTORE or SELFDESTRUCT (0xff). Nothing written after deployment can redirect
  the delegatecall.
- The PUSH20 operand is `raffleImplementation`. It is `immutable` (L42) and assigned only at L91 inside the
  constructor.
- `Clones.clone(address)` (Clones.sol:L32-L34) forwards to `clone(address, 0)` (L47-L62), which uses `create` at L57.
  The `create2` variants are not on this path.

`RaffleFactory` is a plain contract:

```solidity
// RaffleFactory.sol:L21
contract RaffleFactory is IRaffleFactory, ReentrancyGuard {
```

- `IRaffleFactory` is an interface. `ReentrancyGuard` declares only private and internal functions (ReentrancyGuard.sol:
  L88, L94, L102, L112, L116) and keeps its mutex in a fixed storage slot.
- The only external state-changing function is `createRaffle` (RaffleFactory.sol:L97-L148). The factory has no
  `receive` and no `fallback`, so a call with an unknown selector reverts instead of being forwarded.

`Raffle`, the delegatecall target, has no path that replaces or destroys code:

```solidity
// Raffle.sol:L28
contract Raffle is IRaffle, ERC721, ReentrancyGuard, IERC721Receiver, VRFV2PlusWrapperConsumerBase {
```

- Externally reachable state-changing functions: `initialize` L176, `buyEntries` L209, `requestDraw` L240,
  `enableRefunds` L276, `settleWinningTicket` L304, `redeemWinningTicket` L309, `refundTickets` L349,
  `releaseSponsorProceeds` L375, `releaseProtocolFees` L385, `releaseSponsorPrize` L395, `onERC721Received` L416, and
  `receive` L171, which always reverts (L172). Inherited ones: ERC721 `approve`/`setApprovalForAll`/`transferFrom`/
  `safeTransferFrom` (ERC721.sol:L93, L105, L115, L128, L133), and `rawFulfillRandomWords`
  (VRFV2PlusWrapperConsumerBase.sol:L101-L107). The callback is gated to the immutable wrapper at L103 and dispatches
  to Raffle.sol:L509-L524, which only writes storage and emits events. None of these functions writes code or a target
  address, and none executes `delegatecall` or `selfdestruct`.
- `Raffle` has no `fallback`.
- The only assembly in `Raffle` is L266-L268, `call(gas(), refundRecipient, excess, 0, 0, 0, 0)`. That is a CALL, not
  a DELEGATECALL.
- The external dependencies `Raffle` uses are fixed in the implementation's runtime code, which every clone shares:
  `factory` L55, `quoteToken` L58, `i_linkToken` and `i_vrfV2PlusWrapper` (VRFV2PlusWrapperConsumerBase.sol:L34-L35).

---

**How the verdict was reached:** the requirement forbids four mechanisms: UUPS, transparent and beacon proxies, a
mutable delegatecall target, and selfdestruct. Each was searched for in the two contracts and in every base contract
and library they compile against. The one delegatecall the system does execute, in the ERC-1167 runtime, was decoded
and its target is a code literal fed from a constructor-only immutable. The verdict is therefore `implemented` rather
than `partial`, because no path was found where any of the four exists. It is not `stronger-than-spec`, because for
this clause the code adds no constraint beyond the prohibition. The NatSpec claims at RaffleFactory.sol:L18-L19 and
Raffle.sol:L24-L25 were not taken as evidence; each was checked against the code above.

**Open questions:**
- `package.json:L23` deploys through `ignition/modules/RaffleFun.ts`, which is not in the tree, so it cannot be read
  whether deployment puts a proxy in front of `RaffleFactory`. The source limits what such a proxy could do. The
  implementation is created in the factory's own constructor (RaffleFactory.sol:L89), so `Raffle.factory` is that
  contract's address (Raffle.sol:L161). Behind a proxy, `initialize` would be called from the proxy's address
  (RaffleFactory.sol:L109-L121) and would fail `if (msg.sender != factory) revert OnlyFactory();` (Raffle.sol:L178).
  Every proxied `createRaffle` would revert.
- The verdict comes from Solidity source. Compiled bytecode was not inspected. The clone runtime was decoded by hand
  from the constants at Clones.sol:L54-L56.
- Not assessed, and outside the holds-if scope ("Neither the factory nor any raffle"): whether the trusted dependencies
  are upgradeable themselves. DESIGN.md: "Quote token and Chainlink wrapper are trusted canonical dependencies".

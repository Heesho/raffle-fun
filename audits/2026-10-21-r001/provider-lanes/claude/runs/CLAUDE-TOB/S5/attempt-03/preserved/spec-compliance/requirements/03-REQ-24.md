**How the verdict was reached:** every listed parameter is in one of three classes:
- a compile-time constant (entry price, rates, timeouts);
- a constructor-written immutable (quote token, VRF wrapper, factory treasury, implementation, the raffle's `factory`);
- storage written only by the one-shot, factory-gated `initialize` (prize, reserve, end time, recipients, the raffle's treasury copy).

The assignment sweep finds no other writer, and the entrypoint walk finds no function that writes any of these afterwards. `src` contains no `delegatecall`, `sstore`, `selfdestruct` or `StorageSlot` use that could write storage out of band. The ERC-1167 clone has no upgrade surface. The verdict is not `partial` because no path rewrites a listed parameter. It is not `stronger-than-spec` either. The implementation lock (Raffle.sol:L164) and the factory gate (L178) are the means of meeting "fixed once set", not constraints beyond it.

**Open questions:**
- "Administrator" is not defined in DESIGN.md. NatSpec calls the sponsor an "empty-raffle cancellation authority" (IRaffle.sol:L37), exercised at Raffle.sol:L280-L284. The power changes only `status` and leaves every listed parameter alone, so the supplied criterion is met. Whether "No administrator" is meant to exclude a per-raffle privileged actor like this is not settled by the document. How that early close squares with "Refunds open at deadline." is the refund-timing requirement's question, not this one's.
- The deploy module named in package.json:L23 (`ignition/modules/RaffleFun.ts`) is not in the tree, so the files provided do not establish whether the factory is deployed directly. From the source alone, the factory cannot run behind a delegating proxy. Raffle binds `factory = msg.sender` (Raffle.sol:L161) when the factory's constructor runs `new Raffle` (RaffleFactory.sol:L89). `createRaffle` reached through a proxy would call `initialize` from the proxy's address and revert at Raffle.sol:L178.
- Out of scope: the VRF price is read live from the wrapper (Raffle.sol:L437, L442), and USDC behaviour belongs to the token. DESIGN.md: "Quote token and Chainlink wrapper are trusted canonical dependencies". Their addresses are immutable here (RaffleFactory.sol:L33, L36; Raffle.sol:L58; VRFV2PlusWrapperConsumerBase.sol:L35). Whether their own internals can be configured is outside this requirement.

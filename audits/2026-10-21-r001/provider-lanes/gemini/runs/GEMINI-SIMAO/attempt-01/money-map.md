## 2. Tracked Totals & Accounting Variables

| Variable | Type | Writes (`+` / `-` / set) | Meaning / Backing Claim |
|---|---|---|---|
| `totalEntries` | `uint128` | - `buyEntries`: `totalEntries = lastEntry` (`+entryCount`, checked against `type(uint128).max - totalEntries`, `Raffle.sol:219-230`) | Cumulative entries sold. Determines `grossSales() = uint256(totalEntries) * ENTRY_PRICE`, `winningEntry = uint128((randomWords[0] % uint256(totalEntries)) + 1)`, and whether `totalEntries >= reserveEntries` (`NftWon` vs `CashWon`). |
| `ticketCount` | `uint128` | - `buyEntries`: `++ticketCount` (`Raffle.sol:231`) | Sequential counter of minted ERC-721 range tickets (`1..ticketCount`). |
| `_ticketRanges[ticketId]` | `TicketRange { uint128 firstEntry, uint128 lastEntry }` | - `buyEntries`: set once (`firstEntry = totalEntries + 1`, `lastEntry = totalEntries + entryCount`, `Raffle.sol:226-232`). Never deleted on `_burn`. | Inclusive 1-based entry range `[firstEntry, lastEntry]` owned by `ticketId`. |
| `unsettledPot` | `uint256` | - `buyEntries`: `+= grossAmount` (`+uint256(entryCount) * ENTRY_PRICE`, `Raffle.sol:233`)<br>- `enableRefunds`: set to `0` (moved to `remainingRefundLiability`, `Raffle.sol:296-298`)<br>- `_settleWinningTicket`: set to `0` (split into `protocolFees`, `sponsorProceeds`, and optionally `winnerProceeds`, `Raffle.sol:539-555`) | Unallocated quote-token balance prior to terminal settlement or refund activation. |
| `remainingRefundLiability` | `uint256` | - `enableRefunds`: set to `unsettledPot` (`Raffle.sol:296-298`)<br>- `refundTickets`: `-= amount` (`-aggregateEntries * ENTRY_PRICE`, `Raffle.sol:367-368`) | Outstanding quote-token liability owed to unburned tickets in `Status.Refunding`. |
| `winnerProceeds` | `uint256` | - `_settleWinningTicket` (only when `status == Status.CashWon`): set to `cashAmount = Math.mulDiv(grossPot, 8000, 10_000)` (`Raffle.sol:546-548`)<br>- `redeemWinningTicket` (when `status == Status.CashWon`): set to `0` (`Raffle.sol:339-341`) | Quote-token claim allocated to the winning ticket owner in `CashWon`. |
| `sponsorProceeds` | `uint256` | - `_settleWinningTicket`: set to `grossPot - protocolFee` (`NftWon`) or `grossPot - protocolFee - cashAmount` (`CashWon`) (`Raffle.sol:543-554`)<br>- `releaseSponsorProceeds`: set to `0` (`Raffle.sol:376-378`) | Quote-token claim allocated to `sponsorRecipient`. |
| `protocolFees` | `uint256` | - `_settleWinningTicket`: set to `protocolFee = Math.mulDiv(grossPot, 500, 10_000)` (`Raffle.sol:540,555`)<br>- `releaseProtocolFees`: set to `0` (`Raffle.sol:386-388`) | Quote-token claim allocated to `protocolTreasury`. |
| `accountedQuoteBalance()` | `view returns (uint256)` | Sum: `unsettledPot + remainingRefundLiability + winnerProceeds + sponsorProceeds + protocolFees` (`Raffle.sol:468-470`) | Total tracked quote-token liabilities across all lifecycle states. |
| `settlementComplete`, `winnerRedeemed`, `prizeClaimed` | `bool` | Set `true` once in `_settleWinningTicket`, `redeemWinningTicket`, and `redeemWinningTicket`/`releaseSponsorPrize` respectively. | Terminal settlement and claim flags. |

## 4. Protocol Invariants (Derived from `DESIGN.md` & Source)
1. **Quote Conservation (`INV-QUOTE-CONSERVATION`)**: At all times, `accountedQuoteBalance() == unsettledPot + remainingRefundLiability + winnerProceeds + sponsorProceeds + protocolFees <= quoteToken.balanceOf(address(this))`. Specifically, before any claims/refunds, `accountedQuoteBalance() == uint256(totalEntries) * ENTRY_PRICE`.
2. **Exact Settlement Split (`INV-SETTLEMENT-SPLIT`)**: In `_settleWinningTicket`, `protocolFee = floor(grossPot * 500 / 10000)`. If `status == NftWon`, `sponsorAmount = grossPot - protocolFee` and `winnerProceeds == 0`, so `protocolFee + sponsorAmount == grossPot`. If `status == CashWon`, `cashAmount = floor(grossPot * 8000 / 10000)` and `sponsorAmount = grossPot - protocolFee - cashAmount`, so `protocolFee + cashAmount + sponsorAmount == grossPot` with zero dust lost or over-allocated.
3. **Contiguous Partition of Entries (`INV-ENTRY-PARTITION`)**: Tickets `1..ticketCount` form a contiguous, non-overlapping partition of `[1, totalEntries]`: `_ticketRanges[1].firstEntry == 1`, `_ticketRanges[ticketCount].lastEntry == totalEntries`, and for all `1 <= i < ticketCount`, `_ticketRanges[i + 1].firstEntry == _ticketRanges[i].lastEntry + 1`.
4. **Refund Conservation (`INV-REFUND-SOLVENCY`)**: In `Status.Refunding`, each minted ticket `i` can be burned at most once in `refundTickets`, claiming `(_ticketRanges[i].lastEntry - _ticketRanges[i].firstEntry + 1) * ENTRY_PRICE`. If all `1..ticketCount` tickets are refunded, the sum of all refunds equals `uint256(totalEntries) * ENTRY_PRICE`, reducing `remainingRefundLiability` to `0`.
5. **Prize Custody & Exclusivity (`INV-PRIZE-EXCLUSIVITY`)**: Once `status` leaves `AwaitingPrize`, `prizeToken.ownerOf(prizeTokenId) == address(this)` until `prizeClaimed == true`. The prize can be claimed only by the `winningTicketId` owner in `Status.NftWon`, or returned to `sponsorRecipient` in `Status.CashWon` or `Status.Refunding`.
6. **Liveness & No Stuck State (`INV-LIVENESS`)**: Every active raffle can reach a terminal state (`NftWon`, `CashWon`, or `Refunding`) after `endTime`: if `totalEntries == 0`, `enableRefunds()` is callable by `sponsor` before `endTime` and by anyone at `block.timestamp >= endTime`; if `totalEntries > 0`, `requestDraw()` is callable in `[endTime, endTime + 2 days)` and `enableRefunds()` is callable at `block.timestamp >= endTime + 2 days`; if `status == Drawing` and VRF does not fulfill before `drawRequestedAt + 2 days`, `enableRefunds()` is callable at `block.timestamp >= drawRequestedAt + 2 days`.

## 5. Canonical Lifecycles
1. **Reserve Met (`NftWon`)**: `RaffleFactory::createRaffle` (`AwaitingPrize` -> `safeTransferFrom` -> `onERC721Received` -> `Active`) -> `Raffle::buyEntries` (`totalEntries >= reserveEntries`) -> `Raffle::requestDraw` in `[endTime, endTime + 2 days)` (`Drawing`) -> VRF callback `rawFulfillRandomWords` -> `fulfillRandomWords` before `drawRequestedAt + 2 days` (`NftWon`, `winningEntry` in `[1, totalEntries]`) -> `settleWinningTicket(ticketId)` (or inline in `redeemWinningTicket`) -> `redeemWinningTicket(ticketId)` (burns ticket, transfers NFT to `ownerOf(ticketId)`), `releaseSponsorProceeds()` (95% to `sponsorRecipient`), `releaseProtocolFees()` (5% to `protocolTreasury`).
2. **Reserve Missed (`CashWon`)**: Same as above with `0 < totalEntries < reserveEntries` -> `fulfillRandomWords` sets `status = CashWon` -> `_settleWinningTicket` allocates 80% `winnerProceeds`, 5% `protocolFees`, remainder (~15%) `sponsorProceeds` -> `redeemWinningTicket(ticketId)` (burns ticket, pays 80% USDC to `ownerOf(ticketId)`), `releaseSponsorProceeds()`, `releaseProtocolFees()`, and `releaseSponsorPrize()` (returns NFT to `sponsorRecipient`).
3. **Refund Path (`Refunding`)**: Triggered via `enableRefunds()` when (a) `status == Active && totalEntries == 0` (`msg.sender == sponsor || block.timestamp >= endTime`), (b) `status == Active && totalEntries > 0 && block.timestamp >= endTime + 2 days`, or (c) `status == Drawing && block.timestamp >= drawRequestedAt + 2 days`. Moves `unsettledPot` to `remainingRefundLiability`. Ticket owners call `refundTickets(ticketIds)` (burning tickets for 100% USDC refund), and anyone calls `releaseSponsorPrize()` (returning NFT to `sponsorRecipient`).

## 6. Distinct Actor Cohorts
- **`sponsor` & `sponsorRecipient`**: `sponsor` escrows the prize NFT in `createRaffle` and can cancel an empty raffle (`totalEntries == 0`) before `endTime`. `sponsorRecipient` receives sponsor USDC proceeds (95% in `NftWon`, ~15% remainder in `CashWon`) and returned prize NFT (in `CashWon` or `Refunding`).
- **Ticket Buyers / Current Ticket Owners (`ownerOf(ticketId)`)**: Buy entries for `1_000_000` USDC per entry; hold transferable ERC-721 range tickets; whoever owns `winningTicketId` at redemption time burns it in `redeemWinningTicket` for the NFT (`NftWon`) or 80% cash (`CashWon`); in `Refunding`, each ticket's current owner burns it in `refundTickets` for 100% USDC refund.
- **`protocolTreasury`**: Immutable recipient of 5% (`500 bps`) protocol fee on `NftWon` and `CashWon`.
- **Draw Requester / Permissionless Callers**: Any address can call `requestDraw()` (paying native VRF fee), `enableRefunds()`, `settleWinningTicket()`, `releaseSponsorProceeds()`, `releaseProtocolFees()`, and `releaseSponsorPrize()`.
- **Chainlink VRF Wrapper (`i_vrfV2PlusWrapper`)**: Quotes native VRF fee and calls `rawFulfillRandomWords`.

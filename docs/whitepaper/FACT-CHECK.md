## Method

Public claims were checked in this order: production Solidity, executable Foundry and
Hardhat tests, generated ABIs, deployment tooling, security invariants and internal
audit evidence, SDK, subgraph, frontend, architecture notes, and prior prose.

`docs/whitepaper/src/protocol-facts.mjs` parses Solidity constants and status enums,
checks compiled Hardhat ABI functions, generates worked arithmetic, and emits the
ignored build artifact `docs/whitepaper/build/protocol-facts.generated.json`. The
document uses fact tokens resolved from that generated file. `pnpm docs:whitepaper`
fails on unresolved tokens, unexpected status values, missing compiled functions,
page or metadata failures, unembedded fonts, missing searchable phrases, broken
internal links, duplicate page text, or horizontal HTML overflow.
